Tovia Mobile — Especificação de Design

Identidade do App

Nome: Tovia Mobile

Tagline: O app do organizador de eventos

Plataforma: iOS e Android

Propósito: Companheiro operacional para organizadores de eventos — check-in, tarefas e visão financeira. A gestão completa acontece na web (toviaapp.com.br).

Identidade Visual

Paleta de Cores

Backgrounds

Light mode: Screen #f5f5f3 · Card #ffffff · Subtle #FFF4EE · Border #e2e0da

Dark mode: Screen #111110 · Card #1c1c1a · Subtle #3D1506 · Border #2e2e2a

Tipografia & Dimensões

Font: System default (SF Pro iOS, Roboto Android)

Headings: Bold / Black weight · Body: Regular, 15–16sp

Labels: 11sp, uppercase, letter-spacing 0.08em · Dados numéricos: Tabular nums

Radius: 14dp cards · 8dp elementos pequenos · 999dp pills/badges

Shadows: 0 2 12 rgba(255,107,26,0.08)

Esquerda: Logo Tovia Mobile (wordmark, accent laranja no "Mobile")

Direita: Avatar do usuário (círculo, fallback iniciais) + nome — abre profile bottom sheet

Fundo sempre roxo escuro (#2D1470). Aba ativa em laranja primário com ícone preenchido. Abas inativas em creme semitransparente.

Telas

Profile Bottom Sheet

Ativado ao tocar no avatar ou nome na top bar. Sobe a partir de baixo.

  • Handle bar no topo central
  • Header: Avatar grande (64dp, círculo), nome completo em bold 18sp, email em muted 13sp
  • Plan badge: Pill com nome do plano (Chinám / Pétach / Koách / Chalém) em laranja
  • Trial banner (se aplicável): pill amarelo "Trial — X dias restantes"
  • Editar perfil — outlined, largura total — abre toviaapp.com.br no navegador
  • Sair — texto vermelho, sem chevron

Tela 1 — Início (Home)

Header: "Meus Eventos" em bold 22sp. Subtítulo: contagem de eventos ativos.

Event cards (lista com scroll vertical):

  • Nome do evento em bold 16sp
  • Data e local em muted 13sp
  • Contagem de inscritos: "128 inscritos"
  • Toggle switch à direita: laranja = ativo, cinza = inativo
  • Tap no card → tela de detalhe do evento (somente leitura)

Seções:

  • Em andamento — eventos acontecendo hoje (borda esquerda laranja)
  • Próximos eventos — eventos futuros
  • Encerrados — eventos passados (levemente escurecidos)

Estado vazio: Ilustração de calendário + "Você ainda não tem eventos. Crie o seu primeiro em toviaapp.com.br"

Tela 2 — Check-in

2A — Seleção de Evento

Título: "Check-in" bold 22sp. Subtítulo: "Eventos disponíveis hoje".

Event cards apenas para eventos acontecendo hoje: nome, horário, barra de progresso check-ins feitos / total, "48 / 120 presentes" em laranja.

Estado vazio: "Nenhum evento disponível para check-in hoje."

2B — Seleção de Modo de Check-in

Após selecionar um evento, dois cards grandes:

  • QR Code — ícone QR grande (48dp), "Abra a câmera para escanear", background laranja preenchido
  • Lista — ícone lista grande (48dp), "Marque a presença manualmente", card branco com borda laranja

Botão de download offline — largura total:

  • Não baixado: "Baixar lista para uso offline" — outlined laranja
  • Baixado: "Lista salva • Pronto para offline" — laranja preenchido, desabilitado

2C — Scanner QR Code

Tela cheia com câmera. Overlay de scan: quadro centralizado com cantos em branco, linha de scan animada.

  • Top bar: seta voltar + nome do evento
  • Painel inferior: card do último scan (nome + Presente ✓ ou Bloqueado ✗ + motivo)
  • Botão "Ver lista" — navega para 2D
  • Badge offline: "● Offline — sincronizando depois"

Feedback do scan: Sucesso: flash verde + haptic + som. Falha: flash vermelho + haptic.

2D — Lista de Inscritos

Barra de busca fixa "Buscar por nome…". Contador: "48 / 120 presentes" em bold laranja.

Lista alfabética com headers de seção (A, B, C…):

  • Círculo avatar com iniciais (40dp)
  • Nome completo em bold 15sp
  • Checkbox à direita — marcado = laranja preenchido
  • Linhas marcadas: background com tint laranja sutil

FAB: ícone câmera — "Usar QR" — alterna para scanner.
Indicador offline: banner no topo "Modo offline — X pendentes para sincronizar"

Tela 3 — Tarefas

3A — Seleção de Evento

Event cards com badge mostrando contagem de tarefas pendentes: 3 pendentes

3B — Lista de Tarefas do Evento

Filter chips: "Todas" · "Pendentes" · "Em andamento" · "Concluídas"

  • Checkbox (tap para completar — swipe direita também completa)
  • Título da tarefa em bold 14sp
  • Data limite e avatar do responsável em muted 12sp
  • Status chip: Pendente / Em andamento / Concluída

FAB: "+" — cria nova tarefa.

Estado vazio: "Nenhuma tarefa ainda. Crie a primeira!"

3C — Detalhe / Edição de Tarefa

Formulário tela cheia:

  • Título da tarefa (campo de texto editável)
  • Descrição (campo multiline)
  • Data limite (date picker)
  • Responsável (avatar picker, lista de membros)
  • Seletor de status (segmented control)
  • Botão "Salvar" — laranja primário, largura total

Tela 4 — Financeiro

Sub-abas: "Pagamentos" | "Relatórios"

4A — Pagamentos

Barra de busca "Buscar inscrito…". Filter chips: "Todos" · "Pago" · "Pendente" · "Gratuito"

  • Nome em bold 14sp
  • Status chip: Pago / Pendente / Gratuito / Expirado
  • Tap → detalhe (nome, ingresso, data, status com explicação) — somente leitura

4B — Relatórios

Cards resumo (scroll horizontal):

  • "Total arrecadado" — valor R$ em bold laranja
  • "Pendente" — valor R$ em amarelo
  • "Presença" — percentual em bold

Sparkline chart: Inscrições por dia, últimos 30 dias. Preenchimento laranja, grid sutil.

Estatísticas de check-in: % presença, horário de pico (bar chart). Somente leitura, sem exportação.

Tela 5 — Suporte

  • Base de Conhecimento → abre toviaapp.com.br/base-conhecimento
  • Fale Conosco → abre email ou WhatsApp
  • Rever tutorial → reabre fluxo de onboarding
  • Sobre o Tovia Mobile → versão, data do build
  • Política de Privacidade / Termos de Uso → abre navegador
  • Sair — texto vermelho, alerta de confirmação

Tela de Bloqueio Admin

Exibida imediatamente após login para emails de admin (antes de qualquer aba carregar).

  • Ícone de cadeado (48dp, laranja), centralizado
  • Título: "Acesso restrito" bold 20sp
  • Corpo: "A Central Tovia é acessada exclusivamente via web."
  • Botão: "Abrir toviaapp.com.br" — laranja primário, largura total
  • Link "Sair" — muted, faz logout

Onboarding (Primeiro Acesso)

4 slides deslizáveis com page dots. Botão "Pular" nos slides 1–3. "Começar" no slide 4.

  • Slide 1 — Bem-vindo: Logo Tovia Mobile, "Olá, [Nome]!", descrição do app
  • Slide 2 — Check-in: Ilustração scanner QR, destaque para download offline
  • Slide 3 — Tarefas: Ilustração checklist, equipe em tempo real
  • Slide 4 — Pronto!: Checkmark laranja, botão "Começar"
