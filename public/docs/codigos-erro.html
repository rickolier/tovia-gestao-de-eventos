Como registrar um novo erro: Ao identificar um novo erro no Tovia, adicione-o na faixa correspondente com o próximo número disponível. Defina o código interno descritivo (ex: GW-AUTH-401), a mensagem amigável para o organizador e a severidade. O código público nunca deve ser reutilizado, mesmo que o erro seja corrigido.
